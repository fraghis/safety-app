GARDE DNS 2 v3.1 - mode d'emploi

Cette appli est SEPAREE de l'ancienne "Garde DNS". Elle s'installe a cote,
les deux peuvent rester sur le telephone en meme temps.

A) CONSTRUIRE L'APK (GitHub, sans rien installer)
  1. Sur github.com : bouton "+" en haut a droite > "New repository" >
     donne un nom (ex : garde-dns-2) > "Create repository".
  2. Sur la page du depot vide : "Add file" > "Upload files" >
     choisis le fichier GardeDNS2-app.zip (ne le renomme pas) > "Commit changes".
  3. "Add file" > "Create new file" > dans le nom tape exactement :
     .github/workflows/build.yml
     Colle le contenu du fichier de construction donne dans la conversation.
     > "Commit changes".
  4. Onglet "Actions" > attends que ca passe au vert (5 a 10 min) >
     clique sur la ligne en haut > tout en bas, "App-apk" > telecharge.
  5. Si la construction echoue, copie-moi le message d'erreur rouge.

B) INSTALLER SUR LA TABLETTE
  Copie l'APK, ouvre-le, autorise l'installation de sources inconnues.
  C'est une appli distincte : elle n'ecrase pas l'ancienne.
  Les APK sont signes avec la meme cle (debug.keystore.b64), donc les
  prochaines mises a jour s'installeront par-dessus sans desinstaller.

C) PREPARER (dans l'ordre, l'app affiche une liste de controle en haut)
  1. DNS prive (Samsung) : Reglages > Connexions > Plus de parametres de
     connexion > DNS prive > Nom d'hote du fournisseur de DNS prive :
     e758ce.dns.nextdns.io
  2. Dans l'app, bouton 1 : active "Garde DNS 2" dans Accessibilite.
     Si Android refuse (parametres restreints) : bouton 1 bis, puis menu
     en haut a droite > "Autoriser les parametres restreints", puis
     recommence le bouton 1.
  3. Bouton 2 : anti-desinstallation (administrateur).
  4. Bouton 3 : batterie. Choisis "Non restreint" pour Garde DNS 2. Puis dans
     Reglages > Batterie > Limites d'utilisation en arriere-plan : desactive
     "Mettre les applis inutilisees en veille" et ajoute Garde DNS 2 a
     "Applis jamais en veille".
  6. Coche les applications a bloquer de 21h a 6h (Telegram est coche d'office).
  7. Choisis le delai. Pour les premiers jours, garde "1 jour (periode d'essai)".
  8. Appuie sur VERROUILLER (bouton 4) (il faut etre connecte a internet :
     l'heure est verifiee en ligne).

D) CE QUE FAIT L'APP
  - Blocage de nuit (21h-6h, heure du Congo verifiee sur internet) des applis cochees.
  - Pendant le verrou, renvoie a l'accueil si tu ouvres les ecrans : DNS prive,
    Garde DNS 2, Accessibilite, Date et heure / fuseau horaire, partage de
    connexion (USB, Bluetooth, Ethernet), VPN (ajout), utilisateurs / invite,
    Dossier securise, pages NextDNS dans un navigateur.
  - Si le DNS prive est change : navigateurs, Telegram, X, Reddit, Instagram
    et applis cochees sont bloques.
  - L'ecran Accessibilite est inaccessible pendant le verrou (il se rouvre
    pendant la fenetre de deverrouillage). Si la protection est quand meme
    coupee par un autre moyen, c'est note dans le journal.
  - Detection de mots-cles (navigateurs, Telegram, X, Reddit, Instagram) :
    "observation" = journal seulement, "active" = retour a l'accueil.
    Commence en observation.
  - Journal personnel (bouton "Voir le journal") : rien n'est envoye a personne.
    En bas du journal, la section "Ecrans vus dans les Reglages" (diagnostic)
    liste les derniers ecrans ouverts avec leur nom exact, et ceux qui ont ete
    bloques ("-> BLOQUE"). Utile pour signaler un ecran qui passe encore.
  - Les ecrans des Reglages sont reconnus par le nom de la fenetre et son titre
    (plus fiable que les textes de la page), et relus toutes les 500 ms tant
    que tu es dans les Reglages.
  - Bouton "J'ai envie" : pause de 10 minutes avec ton propre texte.
  - Applis jamais bloquees : telephone, SMS, contacts, appareil photo, horloge, cartes.

E) POUR DEVERROUILLER
  "Demander le deverrouillage" (internet requis). Apres le delai choisi, une
  fenetre de 24 h s'ouvre : tu peux changer le DNS, retirer des apps, desactiver
  le verrou ou autoriser la desinstallation. Ensuite le verrou se referme tout seul.

F) LIMITES CONNUES (sans PC)
  - Le mode sans echec de Samsung (volume bas au demarrage) desactive les applis
    tierces. L'app le note dans le journal ("trou de surveillance") mais ne peut
    pas l'empecher.
  - Le blocage de l'ecran Accessibilite repose sur le nom et le titre de la
    fenetre, puis sur des textes d'ecran. Les raccourcis d'accessibilite (touches
    de volume, bouton) ne peuvent pas etre bloques. La vraie solution est le mode
    proprietaire (une commande adb sur PC).
  - Le bouton "Point d'acces" du panneau rapide n'est pas bloque : retire-le du
    panneau (Modifier les boutons). Le partage de connexion actif est note dans
    le journal.
  - Les textes d'ecran dependent de la version d'Android : si un ecran n'est pas
    bloque ou si un ecran utile l'est a tort, dis-le moi avec le nom de l'ecran.
